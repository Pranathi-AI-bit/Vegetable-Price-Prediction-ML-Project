# 🥬 Vegetable Price Prediction Using Machine Learning

## 📌 Project Overview

Vegetable Price Prediction is a Machine Learning-based application developed using Python. The main objective of this project is to predict vegetable market prices based on historical market data.

The application uses machine learning algorithms to analyze previous vegetable prices and estimate future prices. It provides an interactive dashboard where users can select vegetables, states, districts, markets, and prediction dates.

## 🎯 Objectives

- Predict future vegetable market prices using Machine Learning.
- Analyze historical vegetable price trends.
- Help users understand market price variations.
- Provide an easy-to-use interactive dashboard.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest Regressor
- Extra Trees Regressor
- Streamlit
- Matplotlib / Data Visualization

## 🤖 Machine Learning Models

- Random Forest Regressor
- Extra Trees Regressor

**Best Performing Model:** Random Forest Regressor

**Model Evaluation:**
- R² Score: 0.9265
- MAE: ₹322.94 per quintal
- RMSE: ₹485.26 per quintal

*These are evaluation results from the available test dataset, not a guarantee of future prediction accuracy.*

## ✨ Key Features

- Vegetable price prediction
- Historical price analysis
- Vegetable, state, district, and market selection
- Interactive Streamlit dashboard
- Price visualization
- Prediction results in ₹/kg

## 🚀 How to Run the Project

1. Clone this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Run the Streamlit application:

   `streamlit run app.py`

4. Open the local URL displayed in your terminal.
